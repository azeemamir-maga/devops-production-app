Production Practices Demonstrated

Practical DevOps concepts implemented in the project.

🐳

Containerization

Flask runs inside a dedicated Docker container with a production-oriented image configuration.

🔄

CI/CD Automation

GitHub Actions automatically tests, builds, and publishes the application image.

🔐

Container Security

The application container runs as a non-root user and sensitive configuration stays outside Git.

💾

Persistent Storage

PostgreSQL data is stored using the named Docker volume postgres_data.

🌐

Reverse Proxy

Nginx provides the public HTTP entry point and forwards requests to Flask.

🧪

Automated Testing

Pytest and database migrations run as part of the CI pipeline.
